# X投稿案 2026-11-14

## 今日の参考ネタ（Web検索で拾えた範囲）

- Google検索の「AIによる概要」が出る検索では、ブログへのクリックが減っているという調査や記事が多い（数字は調査によってばらつきがある）
- AIでブログ記事を量産しても稼げない、という体験談が目立つ。原因として、独自の情報がない、検索で上位の強いキーワードばかり狙う、などが挙げられている
- 一方で、体験を書いた記事や、少ないアクセスでも買ってもらえる紹介記事はまだ価値がある、という見方

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：逆張り型（ブログは終わった？）
```
「AIのせいでブログは終わった」は、半分だけ本当。

終わったのは
「調べれば分かること」をまとめた記事。

残るのは
「この人がやってみたらどうだったか」の記事。

AIは調べた結果は書けても、あなたの失敗は書けない。
```

### 案2：あるある型（AIでブログ）
```
AIでブログを書き始めた人あるある

・1日で10記事書けて天才だと思う
・1ヶ月後、アクセスがほぼゼロ
・どの記事も同じ顔をしてる
・結局、自分の体験を書いた1本だけ読まれてる

わかる人いる？
```

### 案3：質問型（調べ方の変化）
```
最近、何か調べるとき最初にどこを見てる？

1. Googleの検索結果
2. 検索結果の一番上のAIの答え
3. ChatGPTなどのAIに直接聞く
4. XやYouTube

私は【2か3】。
ブログを書く側としては、ちょっと怖い変化。

番号でリプください！
```

## 投稿のメモ
- 今日は土曜。案2のあるある型は気軽に読めるので週末に合う
- 案1は言い切りの形。ブログを書いている人から引用リポストが来やすい
- 案3の【 】は自分の答えに変える。集まったリプライは、自分がどこで発信するかを決める材料にもなる
