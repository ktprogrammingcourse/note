# X投稿案 2026-11-24

## 今日の参考ネタ（Web検索で拾えた範囲）

- 生成AIがもっともらしい間違いを書く「ハルシネーション」の対策記事が多い
- 文章を確率で作るしくみ上、間違いをゼロにはできない、という説明
- 数字・統計・法律に関わる内容は、公式サイトなどの元の情報で確認すること、人が最後に確認することが基本とされている

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：断言型（責任は自分）
```
AI副業で納品したものに間違いがあったら、謝るのはAIじゃなくて自分。

AIは、ない本の名前も、ない法律も、
自信満々に書くことがある。

だから数字と固有名詞だけは、
必ず元の情報まで見に行く。

それだけで、信用はかなり守れる。
```

### 案2：リスト型（納品前チェック）
```
AIで作ったものを納品する前に確認すること

□ 数字の出どころ
□ 人・会社・商品の名前
□ 日付と曜日
□ 法律や制度の話
□ リンクが本当にあるか

全部を疑わなくていい。
間違えたら困る所だけ、自分の目で見る。
```

### 案3：あるある型（AIの自信）
```
AIあるある

・存在しない本を「おすすめ」してくる
・計算をまちがえても自信満々
・「出典は？」と聞くと、急に謝る
・謝ったあと、また別のまちがいを言う

わかる人いる？
```

## 投稿のメモ
- 案2は保存されやすい形。図にして画像で付けてもよい
- 案3は気軽に読めて、リプライで「こんなことがあった」という体験が集まりやすい
- 案1は言い切りの形。問いかけがない分、引用リポストで意見が来やすい
