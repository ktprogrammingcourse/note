# X投稿案 2026-11-22

## 今日の参考ネタ（Web検索で拾えた範囲）

- 副業の「途中経過」をSNSで発信することが、あとで仕事の応募や依頼につながる、という記事
- 成果が出た人だけが発信を続けるので、ネットの情報は成功例に偏りやすい、という指摘
- フォロワーの数を増やしても仕事につながらなかった、大事なのは「誰が読んでいるか」という体験談

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：逆張り型（結果が出てから発信？）
```
「結果が出てから発信しよう」と思ってる人、逆の方がいいかも。

ネットにあるのは、うまくいった人の話ばかり。

だから、まだ途中の人の
「今週やったこと」「うまくいかなかったこと」は、
同じ場所にいる人にとって一番役に立つ。

途中の記録は、あとで実績にもなる。
```

### 案2：週の記録型（【 】は自分の数字に）
```
AI副業、今週の記録。

応募：【5件】
返事が来た：【1件】
作った見本：【2つ】
使った時間：【合計4時間】

正直、数字はまだ小さい。
でも先週の自分よりは進んでる。

日曜は、1週間を数字で振り返る日にしてる。

今週どうだった？
```

### 案3：断言型（フォロワーより読む人）
```
AI副業の発信で大事なのは、フォロワーの数じゃなくて「誰が読んでるか」。

1万人の知らない人より、
仕事を頼んでくれそうな10人。

その10人が困ってることを書く方が、
ずっと早く仕事につながる。
```

## 投稿のメモ
- 今日は日曜。案2の「週の記録」は、毎週日曜の決まった投稿にすると続けやすく、フォローしてもらう理由にもなる
- 案2は実際の数字がない場合は使わない。数字が小さくても、正直に書く方が信用される
- 案1・案3は言い切りの形。発信している人から引用リポストが来やすい
