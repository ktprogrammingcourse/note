# X投稿案 2026-11-01

## 今日の参考ネタ（Web検索で拾えた範囲）

- 会社員がAI副業をためらう・やめる理由として「時間がない」「帰宅後は疲れて何もできない」が多く挙げられている
- 「週末に予定を詰め込みすぎると続かない。平日に少しずつ、週末は気が向いたら」という実践者の意見
- 成果が出るまで数か月かかるのに、1〜2か月で諦める人が多いという指摘

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：共感型（疲れて何もできない）
```
本業から帰ってきて「よし副業やるぞ」って思えたこと、正直ほぼない。

それで普通だと思う。

だから私は、帰宅後は「AIに下書きを頼むだけ」にした。
直すのは次の日の朝。

疲れてる日に頑張らない方が、むしろ続く。

みんなは何時に作業してる？
```

### 案2：ビフォーアフター型（【 】は自分の体験に）
```
AI副業を始めた頃の私：
「土日に5時間ずつやる」→【3週目で止まった】

今の私：
「平日に毎日15分だけ」→【3ヶ月続いてる】

まとまった時間を作るより、
短い時間を毎日にした方が、結局たくさん進む。

日曜の今日、何分やる？
```

### 案3：断言型（諦める時期）
```
AI副業をやめる人の多くは、結果が出る前の「静かな期間」でやめてる。

最初の数か月は、反応がほぼない。
それは失敗じゃなくて、まだ途中なだけ。

やめるか迷ったら、
「あと1ヶ月だけ、時間を減らして続ける」にしてみて。

今、何ヶ月目？
```

## 投稿のメモ
- 今日は日曜なので、案2の最後の問いかけ（「日曜の今日、何分やる？」）が使いやすい
- 案1は疲れている会社員の共感を集めやすく、リプライで作業時間を答えてもらいやすい
- 案2は実際の体験がない場合は使わない
