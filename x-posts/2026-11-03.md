## 今日の参考ネタ（Web検索で拾えた範囲）

- AIで下書きしたnoteの有料記事を売る副業の記事が多く、「AIで量産」をうたう教材も目立つ
- 手数料が引かれるので、1本売っても手元に残るのは価格より少ない、という試算が出ている
- 「無料記事で信頼を作ってから、有料記事を売る」流れを勧める記事が多い

## 投稿案

### 案1：計算型（必要な販売数）
```
noteの有料記事で月1万円、何本売れば届くか計算してみた。

500円の記事なら20本。
しかも手数料が引かれるから、実際はもっと必要。

20人に「お金を払ってでも読みたい」と思ってもらうのは、
AIで書くより、ずっと難しい。

まず無料記事から始める派？
```

### 案2：逆張り型（AI量産note）
```
「AIでnoteを量産」は、たぶん一番売れない売り方。

読む人が買うのは、文章じゃなくて
「この人の経験なら信じられる」という気持ち。

AIは下書きまで。
失敗した話、迷った話は自分で書く。

そこにしかお金は払われないと思う。
```

### 案3：体験談型（【 】は自分の体験に）
```
初めてのnote有料記事、【1ヶ月で3本】売れた。

買ってくれたのは全員、
【無料記事にコメントをくれた人】だった。

知らない人に売るより、
読んでくれてる人に「続き」を届ける方がずっと早い。

最初の1本、誰が買ってくれた？
```

## 投稿のメモ
- 今日は文化の日（祝日）。休みの日は長めの文章も読まれやすいので、案1の計算の話が合う
- 案2は言い切りの形。問いかけがない分、引用リポストで意見をもらう狙い
- 案3は実際にnoteを売った経験がない場合は使わない
