## 今日の参考ネタ（Web検索で拾えた範囲）

- AIを使ったKindle出版の副業記事が多く、「最短3日で1冊」のような早さをうたうものも目立つ
- KDPではAIで書いた本も出せるが、本文や画像をAIが生成した場合は登録時に申告が必要とされる（人が書いてAIで手直ししただけなら対象外、という整理）
- AIがそのまま書いた本は読まれにくく、レビューで低評価になりやすいという指摘

## 投稿案

### 案1：誤解訂正型（AIで書いた本は出せない？）
```
「AIで書いた本はKindleで出せない」は誤解。

出せる。ただし、
本文や画像をAIが作ったなら、登録の時に申告が必要。

自分で書いて、AIは誤字チェックや言い回しの手直しだけなら、
申告の対象外という整理。

AIで本を出した人、申告した？
```

### 案2：読者目線型（3日で1冊）
```
「AIで3日で1冊」の本、読む側として買いたいかと聞かれたら、正直迷う。

速く作れたかどうかは、読む人には関係ない。

知りたいのは
「この人は、なぜこれを書けるのか」だけ。

書く理由がある人が、AIで速く書くなら最強だと思う。
```

### 案3：質問型（電子書籍の買い方）
```
Kindle本を買うとき、何で決めてる？

1. タイトルと表紙
2. レビューの数
3. 著者のSNSを知ってる
4. Kindle Unlimitedで読めるか

私は【3】。
知ってる人の本なら、多少高くても買っちゃう。

番号でリプください！
```

## 投稿のメモ
- 今日は土曜なので、本の話題は読書する人にも届きやすい

- 案3の【 】は自分の答えに変える
