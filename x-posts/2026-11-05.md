## 今日の参考ネタ（Web検索で拾えた範囲）

- n8n・Dify・GASなどを使った「業務の自動化」を、中小企業から受注する副業の記事が増えている
- n8nは定型作業を裏で自動化、Difyは社内向けのAIチャットボット作り、という使い分けがよく紹介されている
- 作って終わりではなく、月々の保守費を組み合わせる収入の形が紹介されている（金額は個人の事例が中心）

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：リスト型（自動化しやすい作業）
```
小さな会社で「AIで自動化して」と頼まれやすい作業

□ 問い合わせメールの振り分け
□ 毎週の売上をまとめる表
□ よくある質問への返信
□ 請求書の作成と送付

どれも、毎週同じ手順でやってる作業。

身近な会社にある「毎週の面倒」、何がある？
```

### 案2：体験談型（【 】は自分の体験に）
```
初めての自動化の依頼は、【知り合いの事務所の日報まとめ】だった。

【GAS】で組んで、作業時間は【2日】。

でも本当に感謝されたのは、
そのあと「ここ変えたい」に毎月すぐ対応したこと。

作って終わりにしない方が、長く続く仕事になる。
```

### 案3：断言型（ツール選び）
```
AI自動化の副業、最初に覚えるツールは1つでいい。

n8nでも、Difyでも、GASでも。

大事なのはツールより、
「この会社のどの作業が、毎週何時間かかってるか」を聞き出すこと。

それが分かれば、ツールはあとから選べる。
```

## 投稿のメモ
- 案1は会社員・個人事業の人どちらも「うちにもある」と思いやすく、リプライで具体例が集まりやすい
- 案2は実際に自動化を受けた経験がない場合は使わない
- 案3は言い切りの形。問いかけがない分、引用リポストで「私は〇〇派」と返ってきやすい
