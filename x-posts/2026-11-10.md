## 投稿案

### 案1：断言型（要約に価値がある）
```
AIで文字起こしができる今、議事録の副業でお金になるのは「起こす」所じゃない。

・誰が何を決めたか
・次に誰が何をするか

この2つを3行でまとめられる人が、また頼まれる。

全文より、要点がほしい人の方が多い。
```

### 案2：あるある型（文字起こし）
```
AIで議事録を作る副業あるある

・人の名前を毎回ちがう漢字にする
・「えー」「あのー」まで律儀に残す
・2人が同時に話すと、1人の発言になる
・結局、録音を聞き直す

わかる人いる？
```

### 案3：計算型（【 】は自分の数字に）
```
議事録の副業、時給で計算してみた。

音声：【1時間】
AIで起こす：【5分】
聞き直し・整える：【2時間】
報酬：【5,000円】

→ 時給【約2,400円】。

AIで速くなるのは最初だけ。
時給を決めるのは、確認の速さだった。

みんなは音声1時間に何時間かかってる？
```

## 投稿のメモ
- 案1は言い切りの形。問いかけがない分、引用リポストで意見が来やすい
- 案2は気軽に読めるので、平日の朝でも反応をもらいやすい
- 案3は実際の数字がない場合は使わない。時給の計算は自分の数字で出し直す
