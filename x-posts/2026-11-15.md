# X投稿案 2026-11-15

## 今日の参考ネタ（Web検索で拾えた範囲）

- 生成AIの使い方を「教える」副業（セミナー講師・企業研修など）の記事が増えている
- 一番需要が多いのは「ChatGPTなどの基本の使い方」だが、教える人も多く単価は低めという指摘
- シニア向けのAI講座や、自治体・商工会議所の講座が各地で開かれている

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：断言型（一歩先でいい）
```
AIの使い方を教える副業は、専門家じゃなくてもできる。

必要なのは、相手より「一歩先」にいること。

昨日の自分がつまずいた所を、
今日の誰かに教える。

詳しすぎる人より、
最近つまずいた人の説明の方が分かりやすいことも多い。
```

### 案2：体験談型（【 】は自分の体験に）
```
【母】にスマホでAIの使い方を教えたら、すごく喜ばれた。

教えたのは3つだけ。
・声で質問する
・「もっと簡単に」と頼む
・写真を見せて聞く

その時に思った。
これ、地域の講座で困ってる人がたくさんいるはず。

身近な人にAI教えたことある？
```

### 案3：質問型（誰に教わった？）
```
AIの使い方、誰に教わった？

1. 独学（ネット・動画）
2. 会社の研修
3. 友だち・家族
4. 有料の講座

私は【1】。
でも最初の1回だけは、誰かに横で見てほしかった。

番号でリプください！
```

## 投稿のメモ
- 今日は日曜で、家族と過ごす人も多い。案2は家族の話なので共感をもらいやすい
- 案2は実際の体験がない場合は使わない（【母】の部分も自分の相手に変える）
- 案3の【 】は自分の答えに変える。リプライで「横で見てほしかった」という声が集まれば、教える副業の需要のヒントになる
