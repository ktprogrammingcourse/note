# X投稿案 2026-11-17

## 今日の参考ネタ（Web検索で拾えた範囲）

- メルカリやBASEなどに、写真や特徴から商品説明文をAIで作る機能が入り、説明文づくりの手間が減っている
- 小さなブランド向けに、説明文・撮影の指示・SNS運用をまとめて請け負う「ネットショップ運営代行」の副業も紹介されている
- AIの文章は人が確認する前提で使うべきで、特に商品の状態は正直に書くことが大事、という注意

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：逆張り型（公式AIがあるのに？）
```
「出品アプリにAIがあるから、説明文の代行はもう要らない」は、たぶん逆。

AIがあっても、
・何を書けば売れるか
・どこまで書けば返品されないか
は、お店の人にも分からない。

道具がみんなに配られた今、
「使いこなせる人」の方が足りない。
```

### 案2：断言型（状態は正直に）
```
AIで商品説明を書くとき、一番気をつけてほしいのは「盛りすぎ」。

AIは、少しの傷も
「味のある風合い」と書いてくれる。

でも届いた人ががっかりしたら、評価が下がるのはお店の方。

状態だけは、AIに任せず自分の目で書く。
```

### 案3：あるある型（AIの商品説明）
```
AIで商品説明を作ったときあるある

・ただの白いTシャツが「洗練された一枚」になる
・「こだわりの」が3回出てくる
・サイズを書き忘れる
・結局、一番大事な所は自分で書き足す

わかる人いる？
```

## 投稿のメモ
- 案2は、売る人にも買う人にも共感されやすい。商品の状態を正直に書く話は信用につながる
- 案1は言い切りの形。ネットショップをやっている人から引用リポストが来やすい
- 3本とも実績の数字を使っていないので、そのまま使える
