## 投稿案

### 案1：断言型（見た目より順番）
```
AIでスライドがきれいに作れる今、資料作成の副業で差がつくのは見た目じゃない。

・最初の1枚で結論を言う
・1枚に言いたいことは1つ
・読む人の次の行動で終わる

この「順番」を決められる人が頼まれる。

デザインはAIに任せていい。
```

### 案2：あるある型（AIでスライド）
```
AIでスライドを作ったときあるある

・10枚頼んだら、きれいな10枚が出てきて感動する
・よく読むと、何が言いたいか分からない
・アイコンがやたら多い
・結局、1枚目から作り直す

わかる人いる？
```

### 案3：質問型（資料づくりの悩み）
```
仕事の資料づくりで、一番時間がかかるのはどこ？

1. 何を書くか考える
2. 情報を集める
3. 見た目を整える
4. 上司の修正に対応する

私は【1】。
AIのおかげで3は速くなったけど、1はまだ自分の仕事。

番号でリプください！
```
