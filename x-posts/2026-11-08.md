## 今日の参考ネタ（Web検索で拾えた範囲）

- 依頼主から預かった情報を生成AIに入力してよいか、という記事が増えている
- 氏名・会社名・取引内容などは、秘密保持契約がなくても勝手に外に出してよい情報とは限らない、という指摘
- 名前を消しても、業種や金額の組み合わせで誰か分かってしまうことがある。無料版は入力が学習に使われる設定のことが多い

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：断言型（信用）
```
AI副業で一番怖いのは、稼げないことじゃなくて信用をなくすこと。

依頼主の資料を、確認せずにAIに貼る。
それだけで「この人に任せて大丈夫？」になる。

速さより先に、
「AIに入れていいですか？」と一言聞ける人が選ばれる。
```

### 案2：リスト型（AIに入れる前に）
```
依頼主の情報をAIに入れる前に確認すること

□ 契約で外部サービスの利用がOKか
□ 名前を消しても誰か分からないか
□ 無料版の学習設定をオフにしたか
□ 迷ったら依頼主に聞いたか

1つでも怪しければ、架空のデータで試す。

他に気をつけてることある？
```

### 案3：質問型（依頼主への確認）
```
AI副業の人に質問。

依頼主に「AIを使います」って伝えてる？

1. 毎回伝えてる
2. 聞かれたら言う
3. 言ってない
4. 契約書に書いてある

私は【1】。
最初に言っておくと、あとで揉めない。

番号でリプください！
```

## 投稿のメモ
- 案1は言い切りの形。問いかけがない分、引用リポストで意見が来やすい
- 案2は保存されやすい形。図にして画像で付けてもよい
- 契約や法律の判断は一般論にとどめ、「これをやれば絶対安全」とは書かない
- 案3の【 】は自分の答えに変える
