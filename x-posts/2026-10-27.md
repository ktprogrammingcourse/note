# X投稿案 2026-10-27

## 今日の参考ネタ（Web検索で拾えた範囲）

- 生成AI副業は「月数千円のツール代と数時間」で始められる、という参入コストの低さが注目されている
- ココナラなどのスキル販売で、ChatGPTを使った文章作成などを出品する人が増えているという記事が多い
- 中小企業向けの「AI導入支援」が高単価の仕事として取り上げられている

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：断言型（ツール代）
```
AI副業で伸びない人の9割は、ツールに課金しすぎてる。

最初に必要なのは
・無料か月数千円のAI 1つ
・頼んでくれる人 1人

ツールを増やす前に、お客さんを1人増やす方が早い。

今、AIツールに月いくら払ってる？
```

### 案2：ビフォーアフター型（スキル販売・【 】は自分の結果に）
```
ココナラに出品した時の私：
「AIで何でも書きます」→ 反応ゼロ

書き直した後の私：
「飲食店のメニュー説明文、AIで10品まとめて作ります」→【問い合わせが来た】

AI副業は「何でもできる」より「これだけできる」の方が売れる。
```

### 案3：共感型（AI導入支援）
```
会社で「それAIでできない？」って聞かれること、増えてない？

議事録、メール文、マニュアル作り。

実はその「社内でちょっと詳しい人」の立場が、
AI副業のいちばん近い入口だと思う。

社外の知り合いの会社でも、同じ困りごとが待ってるから。

最近何を聞かれた？
```

## 投稿のメモ
- 案1は「ツールに課金しすぎ」に心当たりがある人が多く、リプライで金額を答えてもらいやすい
- 案2は実際に出品して反応が変わった経験がある場合だけ使う（なければ【 】を「書き直した後の方が伸びると思う」などに変える）
- 案3は会社員の読者に刺さりやすい。本業の副業規定には触れていないので、リプライで聞かれたら確認を勧める
