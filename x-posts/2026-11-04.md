## 投稿案

### 案1：誤解訂正型（AI動画は禁止？）
```
「YouTubeはAI動画を禁止した」は誤解。

止められやすいのは
・同じような動画の大量投稿
・他人の動画の差し替えだけ
・AIで専門家のふりをする

AIを使うかどうかより、
「あなたが作る意味があるか」で見られてる。

AI動画やってる人、どう感じてる？
```

### 案2：比較型（伸びる・止まる）
```
AI動画で、止まるチャンネルと残るチャンネルの違い

止まる：
・テンプレに文字を差し替えるだけ
・1日に何十本も出す

残る：
・自分の意見や体験が入ってる
・AIは編集の手間を減らすために使う

AIは「作る係」じゃなくて「手伝う係」。
```

### 案3：質問型（顔出し・声出し）
```
AI副業でYouTubeやるなら、どれでやる？

1. 顔も声も出す
2. 声だけ出す
3. 顔も声もAI
4. YouTubeはやらない

私は【2】。
自分の声が入るだけで「この人が作った」感じが出ると思うから。

番号でリプください！
```
