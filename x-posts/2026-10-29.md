# X投稿案 2026-10-29

## 今日の参考ネタ（Web検索で拾えた範囲）

- 「副業が20万円以下なら確定申告はいらない」という話は所得税だけで、住民税は別に申告が必要、という解説が多い
- 20万円は売上ではなく「所得（売上－経費）」で見る
- 年末が近づき、AI副業の税金・確定申告をまとめた記事が増えている

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。
※ 税金の話は、投稿前に国税庁や住んでいる市区町村のページで確認すること。

## 投稿案

### 案1：誤解訂正型（20万円ルール）
```
「副業20万円以下なら申告いらない」は、半分だけ正解。

いらないのは所得税の確定申告だけ。
住民税の申告は、20万円以下でも別に必要。

しかも20万円は売上じゃなくて「売上－経費」。

AI副業1年目の人、ここ知ってた？
```

### 案2：リスト型（年末にやること）
```
AI副業1年目が年末までにやっておくこと（保存推奨）

□ 今年の売上を月ごとに書き出す
□ AIツールの月額の領収書を集める
□ 副業用の口座を分ける
□ 本業の副業規定をもう一度読む

3月に慌てるかどうかは、12月で決まる。

他にやってることある？
```

### 案3：質問型（記帳）
```
AI副業の売上と経費、何で記録してる？

1. 会計アプリ
2. スプレッドシート
3. 紙のノート
4. まだ何もしてない

私は【2】。
AIに「この明細を表にして」と頼むと、だいぶ楽になる。

番号でリプください！
```

## 投稿のメモ
- 税金の内容は一般的な説明にとどめ、「これで絶対大丈夫」とは書かない
- 「会社にバレない方法」の切り口は使わない（本業の規定確認を勧める方向にする）
- 案3の【 】は自分のやり方に変える
