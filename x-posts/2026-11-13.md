## 今日の参考ネタ（Web検索で拾えた範囲）

- 子育て中・在宅でスキマ時間にAI副業を始める記事が多い
- 子どもの急な体調不良などで作業が止まりやすいので、対応できない時間帯を依頼主に先に伝えておくべき、という指摘
- 稼ぐ前に扶養の範囲や確定申告の基準を確認しておくこと、「主婦でも簡単に高収入」系の高額商材に注意すること、もよく挙げられている

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：共感型（予定どおりにいかない）
```
子育てしながらAI副業してると、予定どおりに進む日の方が少ない。

熱が出る、呼び出しが来る、寝かしつけで一緒に寝る。

だから私は、納期をいつも【2日】早めに自分で決めてる。

予定どおりにいかない前提で組むと、意外と続く。

同じ人いる？
```

### 案2：リスト型（依頼主に先に伝えること）
```
子育て中のAI副業、最初に依頼主に伝えておくこと

□ 連絡が返せない時間帯
□ 急に作業が止まる日があること
□ そのときの連絡方法
□ 納期の余裕がほしいこと

先に言っておくと、
「頼りない人」じゃなくて「信頼できる人」になる。
```

### 案3：断言型（扶養）
```
子育て中のAI副業、稼ぎ始める前に必ず確認してほしいのが「扶養」。

いくらまでなら扶養のままか、
家族の会社の手当はどうなるか。

知らずに超えると、
頑張った分より家計の負担が増えることもある。

確認してから始めても、遅くない。
```

## 投稿のメモ
- 案1の【 】は自分のやり方に変える
- 案3は扶養の具体的な金額は書いていない。制度は変わることがあるので、書くなら国税庁や家族の勤め先・健康保険の案内で確認してから
- 今日は金曜。案1の共感型は、週末に向けて読まれやすい
