## 今日の参考ネタ（Web検索で拾えた範囲）

- 非エンジニアがAIに指示してアプリやサイトを作る「バイブコーディング」で副業を始める記事が増えている
- 中小企業のLP・Webサイト制作や、業務の自動化ツールを受注する方法がよく紹介されている

## 投稿案

### 案1：逆張り型（基礎は要る）
```
「AIがコード書くから勉強いらない」は、ちょっと危ないと思う。

AIは動くものは作れる。
でも、それが安全かどうかは教えてくれないことがある。

HTMLの基本くらい分かると、
AIの間違いに自分で気づける。

バイブコーディング、勉強もしてる派？
```

### 案2：体験談型（【 】は自分の体験に）
```
AIに頼んで【架空のお店のLP】を作ってみた。

かかった時間：【2時間】
自分で直したところ：【スマホ表示と文章】

AIで作るのは一瞬。
「お客さんに出せる形」にするのが本当の仕事だった。

まず練習用に1つ作るのがおすすめ。

何を作ってみた？
```

### 案3：あるある型（バイブコーディング）
```
バイブコーディングあるある

・「いい感じにして」で本当にいい感じになって驚く
・1つ直すと別の所が壊れる
・AIに「さっきの方が良かった」と言いがち
・気づいたら深夜

わかる人いる？
```

## 投稿のメモ
- 案1は賛否が分かれる内容なので、リプライが集まりやすい
- 案2はこのリポジトリの `kurashi-clean.html`（架空のハウスクリーニング会社のLP）を作った体験がそのまま使える。かかった時間などは実際の数字に変える
- 案3は画面のスクショを付けると、画像の拡大表示でも反応がもらえる
