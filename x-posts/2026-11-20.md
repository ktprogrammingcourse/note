## 今日の参考ネタ（Web検索で拾えた範囲）

- 今は会社の年末調整の書類を出す時期。「年末調整をしたら副業の分も終わり」と思っている人への注意を書いた記事が多い
- 年末調整は本業の給与の分だけ。副業の所得は会社では計算されないので、条件によっては自分で確定申告が必要
- 副業の所得が20万円以下でも、住民税の申告が別に必要になる場合がある

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。
※ 税金の話は、投稿前に国税庁や住んでいる市区町村のページで確認すること。

## 投稿案

### 案1：誤解訂正型（年末調整で終わり？）
```
「会社で年末調整したから、副業の税金も終わり」は誤解。

年末調整で計算されるのは、本業の給料の分だけ。

AI副業で稼いだ分は、会社は知らない。
だから条件によっては、自分で確定申告が必要。

今年AI副業を始めた人、ここ大丈夫？
```

### 案2：共感型（年末調整の季節）
```
年末調整の書類を書きながら、
「そういえば副業の分、どうするんだっけ」ってなる時期。

私は今年、【AI副業の売上と経費】を
【スプレッドシート】にまとめ始めた。

今やっておくと、
2月の自分にすごく感謝される。

同じこと考えてた人いる？
```

### 案3：質問型（確定申告の経験）
```
AI副業してる人、確定申告したことある？

1. 毎年してる
2. 今年が初めて
3. まだ必要なほど稼いでない
4. 必要かどうか分からない

私は【2】。
4の人は、今のうちに一度調べておくと安心。

番号でリプください！
```

## 投稿のメモ
- 年末調整の書類を出す今の時期に一番届きやすいテーマ。案1は保存とリプライが集まりやすい
- 10/29の投稿案（20万円ルール・住民税）と内容が近いので、続けて出す場合は間を空ける
- 税金の内容は一般的な説明にとどめ、「これで絶対大丈夫」とは書かない
- 案2・案3の【 】は自分の状況に変える
