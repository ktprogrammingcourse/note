## 投稿案

### 案1：断言型（安売り）
```
AI副業で「AIで速く書けるから安くします」は、自分の首を絞めるだけ。

速さは、相手から見たら当たり前。
お金を払ってもらえるのは「確認・修正・相手に合わせる手間」の方。

値段は、作業時間じゃなくて、
相手が減らせた手間で決めていい。
```

### 案2：裏側公開型（【 】は自分の数字に）
```
AI副業の値段、私はこう決めてる。

AIツール代：【月3,000円】
作業時間：【1件2時間】
自分の時給：【1,500円】

→ 1件【3,500円】以下は受けない。

最初にこの線を決めてから、
安い案件で疲れることが減った。

みんなはどう決めてる？
```

### 案3：質問型（値上げ）
```
AI副業で値上げしたこと、ある？

1. ある（お客さんは残った）
2. ある（お客さんが減った）
3. 怖くてまだできない
4. そもそも値段を決めてない

私は【3】。
値上げのタイミング、みんなの経験を聞きたい。

番号でリプください！
```

## 投稿のメモ
- 今日は月曜なので、仕事の値段の話は会社員にも個人事業の人にも届きやすい
- 案1は最後に問いかけがない代わりに、言い切りで引用リポストを狙う形
- 案2・案3の【 】は自分の数字・答えに変える。値段を決めていない場合は案2は使わない
