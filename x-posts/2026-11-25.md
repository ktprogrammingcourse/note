# X投稿案 2026-11-25

## 今日の参考ネタ（Web検索で拾えた範囲）

- 会社員が副業で業務委託の仕事を受ける場合も、フリーランス法で守られる対象になりうる、という解説が多い
- 発注する側は、取引の条件をメールやメッセージなどの形で示す必要がある（口頭だけでは足りない）
- 受ける側が確認すべき項目として、納品物の範囲、修正の回数や費用、支払日がよく挙げられている

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。
※ 法律の話は、投稿前に公正取引委員会のフリーランス法特設サイトで最新の内容を確認すること。

## 投稿案

### 案1：リスト型（受ける前に決めること）
```
AI副業の仕事を受ける前に、文字で残しておくこと

□ 何をどこまで作るか
□ 修正は何回までか
□ 報酬と支払日
□ AIを使っていいか

口約束だけで始めると、
「これもお願い」が終わらなくなる。

最初に聞くのは失礼じゃない。
```

### 案2：失敗告白型（【 】は自分の体験に）
```
AI副業の最初の案件で、修正が【8回】続いた。

原因は、
最初に「修正は何回まで」を決めてなかったこと。

相手が悪いんじゃなくて、
決めてなかった自分の問題だった。

それからは、受ける前に必ず回数を文字で残してる。
```

### 案3：誤解訂正型（副業でも守られる？）
```
「副業だから、条件があいまいでも仕方ない」は思い込みかも。

会社員の副業でも、業務委託で仕事を受けるなら、
フリーランス法で守られる対象になりうる。

発注する側には、条件を文字で示す決まりがある。

まずは「条件をメッセージで送ってもらえますか？」から。
```

## 投稿のメモ
- 案1は保存されやすい形。図にして画像で付けてもよい
- 案2は実際の体験がない場合は使わない
- 案3は法律の話なので、「必ず守られる」とは書かない。対象になるかは発注者や契約の形で変わるので、詳しくは公正取引委員会のサイトを見るよう添える
