# X投稿案 2026-10-31

## 今日の参考ネタ（Web検索で拾えた範囲）

- AI画像をストック素材サイトなどで売る副業の記事が多く、同時に「商用利用・著作権の注意点」の記事も増えている
- 無料プランでは商用利用できないツールがある、販売先によってはAI生成であることの申告が必要、という指摘が多い
- 既存の作品・実在の人物・有名キャラクターに似せた画像は、審査で落ちたりトラブルになったりしやすい

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。
※ 規約や法律の話は、投稿前に各ツール・販売先の最新の規約で確認すること。

## 投稿案

### 案1：断言型（規約）
```
AI画像で稼ぎたいなら、最初に読むべきはプロンプト集じゃなくて利用規約。

・無料プランだと商用NGのツールがある
・販売先によってはAI生成の申告が必要

ここを飛ばすと、作った画像が全部ムダになるかもしれない。

使ってるツールの規約、読んだことある？
```

### 案2：リスト型（販売前チェック）
```
AI画像を売る前のチェックリスト

□ 使ったツールは商用利用OKのプラン？
□ 有名キャラや実在の人に似てない？
□ ロゴや看板が写り込んでない？
□ 販売先のAI申告ルールに従った？
□ プロンプトと日時を残した？

1つでも迷ったら出品しない。

他に気をつけてることは？
```

### 案3：失敗告白型（【 】は自分の体験に）
```
AI画像をストック素材に【30枚】出したら、【ほぼ全部】審査で落ちた。

理由はだいたい
・指や文字の崩れ
・似たような画像の出しすぎ

AIで「作る」のは一瞬。
「売れる品質まで選んで直す」のに一番時間がかかる。

審査に通ったコツ、教えてほしい。
```

## 投稿のメモ
- 案1・案2は規約や権利の話なので、「これで絶対大丈夫」とは書かない
- 案2は保存されやすい形。図にして画像で付けると、画像の拡大表示でも反応がもらえる
- 案3は実際に出品した経験がない場合は使わない（落ちた理由も自分の体験に合わせて変える）
