## 今日の参考ネタ（Web検索で拾えた範囲）

- 「AI副業は怪しい？」「詐欺の見分け方」という記事が10月も多く出ている
- よくある手口として、仕事を始める前の初期費用の請求や、少額の報酬を払って信用させてから高額な入金を求めるやり方が挙げられている
- 消費者庁もSNSで広がる副業の「もうけ話」に注意を呼びかけている

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：断言型（初期費用）
```
「始めるのにお金が必要」なAI副業は、副業じゃなくて買い物。

まともな仕事なら、
お金はあなたが「もらう」側。

最初に払うのはせいぜいAIツールの月額くらい。
それ以上を求められたら、一度立ち止まっていい。

最初に払ったお金、いくらだった？
```

### 案2：あるある型（勧誘DM）
```
AI副業の発信を始めると届くDMあるある

・「あなたの投稿に可能性を感じました」
・「まずは無料で話しませんか？」
・最初に小さい報酬、あとから大きい請求
・アイコンが全員なぜか似てる

返信しなくて大丈夫です。

他にどんなDM来た？
```

### 案3：数字×結果型（【 】は自分の数字に）
```
AI副業に使ったお金を全部書き出してみた。

ツール：【月3,000円】
教材：【0円】
収益：【月1万円】

正直、お金をかけた所より、
人に聞いて回った時間の方が利益になってた。

AI副業、いくら使っていくら稼いだ？
```

## 投稿のメモ
- 案1・案2は詐欺への注意喚起なので、特定の人やサービス名は出さない
- 案2の最後の問いかけは、リプライで手口が集まりやすい（集まったら翌日のネタにも使える）
- 案3は実際の数字がない場合は使わない
