## 今日の参考ネタ（Web検索で拾えた範囲）

- 指示するとAIが作業を進めてくれる「AIエージェント」を副業に使う記事が増えている
- 「丸投げで稼ぐ」より「作業時間を減らして、時間あたりの稼ぎを上げる道具」として使う見方が主流
- 任せやすい作業として、提案文の下書き・定型メール・SNS投稿案づくりなどが挙げられている

※ インプレッション数を確認できた投稿ではなく、検索で目立った話題からの推定。

## 投稿案

### 案1：比較型（任せていい・ダメ）
```
AIエージェントに任せていいこと・ダメなこと

任せていい：
・提案文の下書き
・定型メールの返信案
・調べ物のまとめ

任せちゃダメ：
・依頼主への最終の送信
・金額の約束
・「できます」と言うかどうか

決めるのは、最後まで自分。
```

### 案2：ビフォーアフター型（【 】は自分の体験に）
```
AIエージェントを使う前の私：
1件の提案文に【40分】

使い始めた後の私：
下書きはAI、直すのは私で【15分】

浮いた時間で、応募の数を【1日1件→3件】に。

AIで稼ぐというより、
AIで「挑戦できる回数」が増えた感じ。
```

### 案3：質問型（何を任せている？）
```
AI副業の人に聞きたい。

AIに一番任せてる作業は？

1. 下書き・文章づくり
2. 調べ物
3. スケジュール・メール管理
4. 画像・資料づくり

私は【1】。
ゼロから書くより、直す方が圧倒的に速い。

番号でリプください！
```

## 投稿のメモ
- 案1は図にして画像で付けると保存されやすい。最後は言い切りで、引用リポストを狙う
- 案2は実際の体験がない場合は使わない
- 案3の【 】は自分の答えに変える
