## 投稿案

### 案1：あるある型（AI翻訳）
```
AI翻訳を直す仕事あるある

・文法は完璧なのに、なぜか冷たい
・固有名詞をしれっと訳しちゃう
・「お世話になっております」の英訳で毎回悩む
・結局、日本語の方を直したくなる

わかる人いる？
```

### 案2：断言型（英語力）
```
「AIがあるから英語力いらない」は、翻訳の副業では逆だと思う。

AIの訳が間違ってるかどうかは、
英語が分かる人にしか見抜けない。

AIのおかげで速くなった分、
最後の確認ができる人の価値は上がってる。
```

