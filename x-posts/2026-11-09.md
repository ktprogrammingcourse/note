## 投稿案

### 案1：逆張り型（実績ゼロを隠さない）
```
AI副業の応募文で「実績ゼロ」を隠すのは、逆効果だと思う。

発注する人が知りたいのは、
・何ができるか
・それを見せられるか
・ちゃんと連絡が取れるか

実績がないなら、作った見本を1つ添えて正直に書く。
それで十分、選ばれることはある。
```

### 案2：手順型（最初の1件まで）
```
実績ゼロからAI副業の最初の1件を取るまで

1. やる仕事を1つに決める
2. 架空の依頼主を想定して、見本を3つ作る
3. プロフィールに見本を載せる
4. 応募は1日3件、2週間続ける

才能より、4を続けられるかどうか。

今、何番まで来てる？
```

### 案3：共感型（応募が怖い）
```
AI副業、応募ボタンを押すのが一番怖くない？

「実績ないのに応募していいのかな」
「返事が来なかったらどうしよう」

でも返事が来なくても、何も失わない。
落ちた応募の数だけ、応募文がうまくなる。

最初の応募、何日迷った？
```

## 投稿のメモ
- 今日は月曜なので、「今週こそ始めたい」人に届きやすい手順型（案2）が合う
- 案2は図にして画像で付けると保存されやすい
- 3本とも実績の数字を使っていないので、そのまま使える
